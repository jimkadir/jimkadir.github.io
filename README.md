# Md Abdul Kadir — Portfolio Website

Free static website prepared for GitHub Pages.

## Before publishing
1. Open `index.html` and replace `YOUR_EMAIL@example.com` with your actual professional email address. Update the email subject link if needed.
2. Replace the three "Sample coming soon" cards with links to actual published work you have permission to showcase. The current artwork is decorative only.
3. The studio portrait is AI-edited from a supplied photograph. Consider a clear original headshot too if authenticity is important.
4. Verify all statements and services accurately describe your work.

## Publish at https://jimkadir.github.io
1. Sign in to GitHub as `jimkadir`.
2. Create a **public** repository named exactly `jimkadir.github.io`.
3. Upload the contents of this folder (`index.html`, `styles.css`, `script.js`, `assets/`) to the repository root, not a nested folder.
4. In the repository, go to Settings → Pages → Build and deployment. Select **Deploy from a branch**, choose **main** and **/(root)**, then Save.
5. Wait for deployment, then visit https://jimkadir.github.io.

This is a static website. No hosting purchase is required for GitHub Pages public repositories under the applicable free-tier terms.
